# thetiny.site — Homepage Recreation

Intern Front-end Developer assignment for **Bangla Puzzle Limited**.
A pixel-faithful, fully responsive recreation of the [thetiny.site](https://thetiny.site) homepage.
The design was referenced visually and rebuilt entirely from scratch — no copied source code, no frameworks, no CMS.

## Tech Stack
- **HTML5** — semantic, accessible markup
- **Tailwind CSS v3** — utility styling, compiled via the Node CLI
- **Vanilla JavaScript** — all interactions, zero dependencies
- **Node.js** — local dev server + Tailwind build pipeline

## Features
- Fully responsive layout (mobile / tablet / desktop)
- Fixed, semi-transparent navbar with a mobile hamburger menu
- Hero section with login card and a solid-violet stats band
- "Most Popular Links" cards with working **copy-to-clipboard** and a **QR-code modal**
- Premium analytics-dashboard mockup with animated progress bars
- Three-tier pricing, testimonial, and feature sections
- Complete footer with contact details and legal links
- Palette-matched custom scrollbar and `prefers-reduced-motion` support

## Run Locally
```bash
npm install
npm run dev     # terminal 1 — builds CSS (watch mode)
npm start       # terminal 2 — serves at http://localhost:3000
```
